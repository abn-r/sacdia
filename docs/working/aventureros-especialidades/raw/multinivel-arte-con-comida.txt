Crear un mosaico de semillas.
    Estampar una imagen o diseño usando frutas y/o vegetales.
    Hacer una guirnalda de frutas para pájaros.
    Construir al menos 2 meriendas de arte de frutas y/o vegetales comestibles.
    Teñir una camiseta con vegetales y/o frutas.











 * Esté al tanto de cualquier alergia alimentaria que tengan los niños. Esto incluye alergias al
 comer o tocar alimentos específicos.

          Lea Génesis 1:6. Discuta y muestre ejemplos de semillas comestibles. Para ver ejemplos
          de mosaicos de semillas, busque por internet usando las palabras clave «mosaicos de
          semillas    manualidades       para  niños».  Para  niños  más  pequeños,  use  una  imagen
          preimpresa.
          Busque por internet manualidades de estampado de frutas y verduras para niños.
          Para ver ejemplos de guirnaldas de frutas para pájaros, busque por internet o busque
          manualidades de comederos de pájaros con guirnaldas de frutas para niños.
          Encuentre manualidades saludables y divertidas con alimentos comestibles para niños
          en Pinterest o en libros de cocina para niños.
          Busque     por internet usando la palabra clave de búsqueda                    «teñir una camisa con
          vegetales y frutas». Esto puede ser complicado, así que considere proporcionar guantes
          desechables y camisas viejas como batas para cubrir la ropa de los niños.
