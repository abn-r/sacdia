ficha 10. Camporees: ficha 11. Supervisión: ficha 12. Operación de sección
(recorte demo): ficha 13. Contrastadas con código al 2026-09-14.
Gestión de clubes y RBAC se consultaron para fundamentos y detección de
discrepancias, no se auditaron completos.

El [mapa de producto para la iglesia](14-mapa-producto-iglesia.md) cubre el
universo de venta (incluido tesorería, inventario, materiales, ranking, SLA,
comunicaciones y huecos). No sustituye una ficha de flujo de cada dominio
marcado como Pendiente.

El registro no es exhaustivo: durante cada bloque se buscarán capacidades nuevas,
flujos transversales y cambios posteriores al corte. Por ejemplo, continuidad anual
y responsabilidades pedagógicas requieren revisión propia aunque no sean filas
independientes en este índice. La clasificación institucional tiene enlaces a spec
/plan en la fuente; no se toma ese material como prueba de despliegue.
