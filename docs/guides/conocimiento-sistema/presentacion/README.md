## Qué cubre el deck

Alcance, club ≠ sección ≠ año, beneficios con condiciones, responsabilidades,
ingreso, ciclo anual, evidencia ≠ validación, **lo que corresponde a Unión**
(camporee, carpeta, informes, tablero), dos interfaces, límites, piloto.

Qué queda en notas / concentrado: clases vs honores vs certificaciones,
scoring de jueces, flag de órdenes de pago, fórmulas de ranking, finanzas,
inventario.

## Honestidad (lámina y voz)

Beneficio + condición. Código ≠ pantalla. Cargo ≠ permiso. Fecha de corte:
septiembre 2026. Cierre: piloto acotado, no “listo en toda la Unión”.
